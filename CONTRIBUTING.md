# Contributing

PRs welcome — please keep the bar that makes this repo useful:

1. Attempt the problem cold for 30 minutes before asking for help; include what you tried.
2. Every code example must run: `python -m pytest -v` green before submit.
3. If behavior changes, re-run benchmarks + experiments and commit updated `results/`.
4. Keep README scannable: tables over prose, working commands over philosophy.
5. No secrets in examples or recordings (`assets/demo.*` must show only timings + public quotes).

Fork → `feature/<name>` → PR with before/after numbers.
